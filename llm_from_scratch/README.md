# LLM From Scratch

The goal of this subdirectory is to progressively build increasingly complex LLMs. Each incrementally more complex LLM will be given its own version and associated subdirectory, as follows: `v0/`, `v1/`, `v2/`, and so on. `v0/` will contain a decoder only transformer model for text generation, with the decoder architecture being ripped straight from "Attention Is All You Need".

The goal of this subdirectory `llm-from-sratch` is to reach a "from first principles" understanding of modern LLMs - well, at least the core of them; their essence. I'm sure the big AI labs have many bells ad whistles (and probably major architectural differences) that stray away from the most advanced model versions we can build here, but I believe we can still get great value here from an educational perspective.
